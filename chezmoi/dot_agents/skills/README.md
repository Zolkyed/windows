# Skills

Skills used to assist with the development of the Electron + MCP application.

| Skill | Purpose |
|---|---|
| [`mcp-builder`](./mcp-builder) | Helps design and build MCP servers and tools, including tool schemas, server structure, and MCP best practices. |
| [`skill-creator`](./skill-creator) | Creates and improves custom Skills for application-specific workflows and agent behavior. |
| [`webapp-testing`](./webapp-testing) | Tests the WebUI and extension using browser automation and validates user workflows. |
| [`frontend-design`](./frontend-design) | Helps create polished, accessible, production-quality interfaces for the Electron WebUI. |
| [`web-artifacts-builder`](./web-artifacts-builder) | Generates interactive web components and artifacts for the application's WebUI. |
| [`github-issue-workflow`](./github-issue-workflow) | Triage, branch, implement, and PR workflow for resolving GitHub issues with `gh`. |

Source: [anthropics/skills](https://github.com/anthropics/skills), installed via `npx skills add`.
